# 📊 Dashboard for Any Dataset

This Streamlit app allows users to upload and explore any CSV dataset through interactive visualizations.

## 🔍 Features
- Generate histograms, scatter plots, pie charts, and KDE plots
- Filter and preview your dataset easily

## 🚀 How to Use
1. Upload a CSV file
2. Select visualization type from the sidebar
3. Interact with the plots to explore your data

## 🛠️ Built With
- Python
- Streamlit
- Pandas
- Matplotlib
- Plotly

## 📎 Example
Try it online: [Quick Insights App](https://quickinsights.streamlit.app/)
